# 2026-08-24 项目增强（企业级框架改造）

将 Playwright+Pytest 电商自动化项目从“脚本集合”提升为企业级框架。
目标站点：automationexercise.com（公开练习站）。

## 已完成
- P0 配置管理：新增 config/config.yaml（共享默认）+ test/dev/prod.yaml；
  config_reader.load_config(env) 合并二者，测试环境可配置。
- P0 多浏览器：通过 pytest-playwright 的 `--browser` 选项参数化
  （pytest.ini addopts 写入三个 --browser），用例 ×3 内核。
  注意：不能再自定义 browser_name 固件（与插件 pytest_generate_tests
  冲突报 duplicate parametrization），必须走 --browser 选项。
- P0 README：企业级英文 README.md（结构/特性/覆盖/运行/CI）。
- P1 utils/assertions.py：统一断言封装，新测试统一使用。
- P1 增强日志：conftest 增加 START TEST / END TEST PASS|FAIL /
  失败 URL / 异常 / 失败截图（pytest_runtest_setup + makereport）。
- P1 新业务测试：
  test_register.py（正常/邮箱重复/空字段，UI 删号清理）
  test_product_category.py（Women/Men/Kids）
  test_cart_multi.py（多商品购物车：数量/名称/单价/行总价/合计）
  test_checkout_full.py（地址/商品/总价/订单生成/发票校验）
- P2 faker 测试数据（注册/接口/混合用例）；GitHub Actions
  .github/workflows/test.yml（三浏览器+Allure 历史趋势）。
- P3 api/api_client.py（requests 封装）；api_tests/（products/login/register
  接口测试）；tests/test_api_ui_register.py（API 建号→UI 登录 混合）；
  utils/db_helper.py（数据库校验，未配置则 pytest.skip）。

## 关键坑
- 公开站 /api/deleteAccount 接口当前返回 405（不可用），
  账号清理改用 UI `/delete_account`（注册/混合用例），纯接口用例 best-effort。
- 购物车“总价”区域 (.total_area) 在当前站点版本未稳定渲染，
  get_grand_total() 返回 None，多商品总价改用“行总价之和”校验。
- 非登录用例是 guest 购物车（每测试全新 context），确定性好；
  登录/结算用例用服务端持久化的 zoe 账号，需 clear_cart() 清残留。
- 全部浏览器已安装（chromium/firefox/webkit），无需 playwright install。
